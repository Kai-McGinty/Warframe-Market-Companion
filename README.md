# Warframe-Market-Companion
### Summary
This project is intented to be a warframe trading app using the warframe.market API to retrieve and compare prices to find items with high profit margins and place market orders on identified items

### Features
- Interactive front end interface [**WIP**]
- Item retrieval (buy and sell price, item volume, running average price of top 6 listings) [**WIP**]
- Automatic profit hunter (look for decent profit margins on items) [**WIP**]
- Automatic buy and sell requests [**WIP**]
